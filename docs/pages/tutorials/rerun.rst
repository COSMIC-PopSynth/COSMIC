###################
Re-running binaries
###################

``COSMIC`` can re-run binaries that have already been evolved previously. This allows users to either re-run identical simulations from others, re-run those same initial conditions with modified settings, or restart a binary midway through its evolution. Follow the tutorials below to learn how to do this!
